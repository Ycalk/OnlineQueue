# Online Queue Service

Проект по созданию онлайн-системы управления очередями и записью на прием. Реализован в виде модульного монолита (Modular Monolith) с использованием современных практик разработки на Python и TypeScript.

## Технический стек

### Backend

- **Язык:** Python 3.12+
- **Фреймворк:** FastAPI  (асинхронный веб-фреймворк)
- **База данных:** PostgreSQL (с разделением на схемы `user_schema`, `queue_schema`)
- **ORM:** SQLAlchemy (Async)
- **Миграции:** Alembic
- **DI Container:** Dishka (внедрение зависимостей)
- **Архитектура:** Clean Architecture / Hexagonal Architecture + DDD + CQRS
- **Инструменты:** Pydantic (валидация), Poetry (управление зависимостями)

### Frontend

- **Язык:** TypeScript
- **Фреймворк:** React 19
- **Сборщик:** Vite
- **UI Kit:** Mantine UI 7

## Архитектура

Проект следует принципам **Clean Architecture** и разделен на независимые модули (Bounded Contexts):

### Модули (Modules)

1. **User (`modules/user`)**:
    - Управление пользователями, аутентификация, профили.
2. **Queue (`modules/queue`)**:
    - Управление очередями (создание, настройка, активация/деактивация).
    - Учет заявок в рамках очереди.
3. **Request (`modules/request`)** *(в процессе)*:
    - Жизненный цикл заявки (создание, подтверждение, отклонение).

### Слои (Layers)

Внутри каждого модуля соблюдается слоистая структура:

- **Domain**: Ядро бизнес-логики. Содержит Сущности (Entities), Агрегаты (Aggregates), Value Objects и Доменные события. Не зависит от фреймворков.

- **Application**: Сценарии использования (Use Cases / Commands & Queries). Оркестрирует поток данных. Содержит порты (интерфейсы).
- **Adapters**:
  - **Inbound (Входящие):** REST API (FastAPI роутеры).
  - **Outbound (Исходящие):** Реализация репозиториев (Persistence), внешние клиенты.

### Паттерны

- **CQRS**: Разделение операций чтения (Queries -> DTO) и записи (Commands -> Domain Model).
- **DI (Dependency Injection)**: Все зависимости внедряются через контейнер `Dishka`.
- **Rich Domain Model**: Логика инкапсулирована в сущностях.

## 🚀 Основные возможности (на текущем этапе)

- Регистрация и авторизация пользователей.
- CRUD операции для очередей.
- Активация/деактивация очередей.
- Просмотр списка очередей (с фильтрацией и пагинацией).
- Просмотр очередей текущего пользователя.
- (WIP) Создание заявок на запись.
